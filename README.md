# 🚀 TurboSpace Optimizer

Android Game Booster

TurboSpace Optimizer is an Android game booster designed to provide
quick access to game performance tools through a floating in-game overlay.

## ✨ Features

- 🎮 Game Booster Overlay
- 🖱️ Movable Floating Overlay
- 🧹 RAM Optimization
- 🌐 Network Optimization
- ⚡ CPU Optimization
- 🔕 Do Not Disturb integration
- 🎯 Game-focused performance tools

## 📦 Installation

1. Download the latest APK.
2. Open the downloaded APK on your Android device.
3. Allow installation if Android asks for permission.
4. Install TurboSpace Optimizer.
5. Open the app and grant the permissions requested by the app.

## ⚠️ Permissions

TurboSpace may request permissions required for features such as
the floating game overlay and Do Not Disturb access.
